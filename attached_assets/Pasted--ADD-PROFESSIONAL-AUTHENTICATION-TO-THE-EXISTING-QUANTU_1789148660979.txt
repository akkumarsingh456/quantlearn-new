# 18. SECURITY

Follow secure authentication practices.

IMPORTANT:

* Never store plaintext passwords.
* Never expose password hashes to the frontend.
* Validate all backend inputs.
* Protect private API routes.
* Prevent users from accessing another user's data by changing IDs in requests.
* Do not trust user IDs supplied by the frontend when determining ownership.
* Use the authenticated user's identity on the backend.
* Handle expired/invalid authentication correctly.
* Avoid exposing sensitive authentication errors.
* Use secure token/session handling appropriate for the application architecture.
* Configure CORS correctly.
* Do not hard-code secrets.
* Use environment variables for secrets/API keys.

Do not put secret API keys in frontend code.
